AdCraft Backend Blueprint v1

Everything the frontend needs to go live: lead capture API, database, email notifications, admin view, security, hosting and a phased build order. Stack is deliberately boring and cheap to run: Next.js frontend (this design, ported), a small Node API, Postgres, and managed email.

1 · System architecture

Four layers, nothing exotic

🌐 Frontend

  • Next.js (App Router) — this design
  • Static marketing pages + forms
  • Hosted on Vercel
  • Analytics: Plausible / GA4

⚙️ API Layer

  • Node.js + Fastify (or Next API routes for MVP)
  • REST: /api/leads, /api/audit-requests
  • Validation: Zod schemas
  • Rate-limit + Turnstile captcha

🗄️ Data

  • PostgreSQL (Neon / Supabase)
  • Tables: leads, companies, audit_requests, messages
  • Prisma ORM + migrations
  • Daily automated backups

🔔 Services

  • Email: Resend / SES — team alert + client auto-reply
  • CRM sync (later): HubSpot / Zoho
  • WhatsApp notify (later): official API
  • Files: S3-compatible storage
Browser ──► Vercel (Next.js frontend)
   │              │

   │              ▼
   └────►  API (Fastify / Next route) ──► Postgres (leads, audits)

2 · Data model

Core tables (MVP)

-- leads
id            UUID PK
name          TEXT NOT NULL
company       TEXT NOT NULL
contact       TEXT            -- email or phone
team_size     TEXT
pain_points   TEXT
source        TEXT DEFAULT 'website'
status        TEXT DEFAULT 'new'  -- new | contacted | audit_booked | proposal | won | lost
created_at    TIMESTAMPTZ DEFAULT now()

-- audit_requests  (1 lead → many)
id, lead_id FK, preferred_time, notes, created_at

-- admin_users
id, email UNIQUE, password_hash (argon2), role -- admin | viewer

-- events (audit log)
id, lead_id FK, type, payload JSONB, created_at

4 · Security & ops
  • Secrets only in env vars / host secret store — never in repo
  • Turnstile + rate-limit (10 req/min/IP) on all public POSTs
  • Admin behind login + session cookie (httpOnly, secure)
  • Input validation on every field; no raw SQL — Prisma only
  • HTTPS everywhere, CORS locked to adcraftautomations.com
  • Logs: structured JSON; error alerts to team email
  • Backups: daily DB snapshot, 14-day retention
5 · Build order

Phased rollout

Phase 1 — Now ✓

Frontend (this page). Design, copy, ROI calculator, blueprint, logo locked — Gears AC in Electric Blue on white (Website view), engagement models, portal preview, insights and security sections. Form is visual-only and generates a downloadable brief.

Phase 2 — MVP Backend

Next.js port + POST /api/leads + Postgres + Resend emails + simple admin list. Target: first real lead captured end-to-end.

Phase 3 — Grow

CRM sync, WhatsApp notifications, client portal (login, project status, automation health, monthly ROI reports, document vault, support tickets — spec in section 6), blog/CMS for SEO.

Hosting & cost shape (indicative)

Vercel (frontend) + Neon/Supabase (Postgres) + Resend (email) all have free tiers that cover launch volume; paid tiers only kick in as leads grow. Domain: adcraftautomations.com via Cloudflare DNS. No servers to maintain at MVP stage.
